# Goal title, then "> finish condition", then "- Subgoal" / " - Nested subgoal" / "* Task @2026-12-01". More "> " lines = goal notes (links work). A "* " indented under another "* " = subtask. 🔁 = habit, e.g. "* Run 🔁 3/week" or "🔁 2/day". @date = assigned day (shows on the calendar that day). Goal tasks don't use due dates, so a !date is ignored — goal tasks stay on the goal page and never appear in the Deadlines tab or the Backlog.
